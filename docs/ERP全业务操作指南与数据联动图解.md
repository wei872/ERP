## 1. 前言：ERP 数据闭环运转总揽

本 ERP 系统最大的特色是 **“极简操作，深度自动联动”**。一线操作人员在界面上完成一次业务动作（如点击【入库】或【核销】），系统会自动同步更新**仓库库存、出入库日志、商品成本、订单状态、应收应付账款以及财务记账总账凭证**，避免人工重复搬运数据。

### 场景 1：📊 控制台 (Dashboard) — 经营驾驶舱

#### 📌 功能定位与适用场景
总经理、部门主管日查看的经营看板。实时掌握企业销售额、采购额、订单数、资金存货分布与热销商品。

#### 📝 分步操作指南
1. 点击左侧导航栏 **【控制台】**。
2. 查看顶部 **KPI 指标卡片**（销售总额、采购总额、订单数、净利润）。
3. 鼠标悬停在柱状图与饼图上，查看各月份销售/采购具体数值，以及存货资产在各商品分类中的占比。

#### 🔄 后台数据自动联动逻辑
- **数据源**：实时聚合 `trade_sales_main`（销售总额）、`trade_purchase_main`（采购总额）、`trade_inventory_balance`（库存资产分布）、`account_subject_balance`（净利润 4104 科目）。
- **联动效应**：当出入库、核销或月结完成后，刷新控制台页面，KPI 与图表**自动同步更新**。

---

### 场景 2：📈 报表中心 (Report Center) — 多维报表穿透

#### 📌 功能定位与适用场景
管理层与数据分析员用于按周期分析销售、采购、库存变动、财务收支、生产产出和人力分布。

#### 📝 分步操作指南
1. 点击左侧导航栏 **【报表中心】**。
2. 在顶部选择切换按钮 **【周度 (Weekly)】 / 【月度 (Monthly)】 / 【年度 (Yearly)】**。
3. 页面将自动切换对应的统计粒度，直观展示 6 大维度的变动折线图与柱状图。

#### 🔄 后台数据自动联动逻辑
- 聚合 `trade_stock_log`（库存变动）、`finance_income_main`/`expense_main`（财务资金收支流水）、`prod_work_order`（生产产出）。

---

### 场景 3：🔁 工作流审批 (Workflow) — 多级协同与费用自动记账

#### 📌 功能定位与适用场景
员工提交采购申请、费用报销或请假单；部门经理与高管进行多级审批流转。

#### 📝 分步操作指南
* **途径 A（在工作流页面直接发起）**：
  1. 点击 **【工作流审批】 ➔ 【提交新审批】** 标签页。
  2. 选择类型（如`费用审批`）、关联单号、金额及事由，点击【提交审批】。
* **途径 B（在采购列表中 1 键提报）**：
  1. 打开【数据模块 ➔ 进销存 ➔ 采购订单主表 (`trade_purchase_main`)】。
  2. 在目标采购单行点击 **`🔁 提审批`**，系统自动将该单号与金额推送到工作流。
* **审批人操作**：
  1. 审批人登录后，在【我的待办】中查看任务，点击【详情】。
  2. 在弹窗中输入审批意见，点击 **【通过】** 或 **【驳回】**。

#### 🔄 后台数据自动联动逻辑
- **采购审批通过**：自动将 `trade_purchase_main.purchase_status` 更新为 `'已审批'`。
- **费用审批通过**：自动向 `finance_expense_main` 写入支出流水，并**自动生成费用凭证（借:6602管理费用 贷:1002银行存款）**，更新总账科目余额！

---

### 场景 4：🛒 采购订单 ➔ 📦 一键入库 ➔ 自动重算加权成本与应付账款

#### 📌 功能定位与适用场景
采购到货验收后，仓库人员一键入库，系统自动增加库存、更新重算存货加权平均成本，并挂接供应商应付账款。

#### 📝 分步操作指南
1. **新建采购单**：打开【数据模块 ➔ 进销存 ➔ 采购订单主表 (`trade_purchase_main`)】，点击 **`+ 新增`**，录入供应商与总金额并保存。
2. **一键提审批**：在采购单行点击 **`🔁 提审批`**，送入工作流。
3. **一键采购入库**：货物送达后，在采购单行点击 **`📦 入库`** 按钮。
4. 页面顶部提示 `✅ 采购单入库成功，库存与到货状态已联动更新！`。

#### 🔄 后台数据自动联动逻辑
- **单据自动生成**：自动创建 `trade_stock_in_main` 与明细 `trade_stock_in_detail`。
- **加权成本计算**：自动按公式 $\text{新均价} = \frac{\text{旧总价值} + \text{入库数量} \times \text{采购价}}{\text{旧数量} + \text{入库数量}}$ 重算 `trade_inventory_balance` 的 `unit_cost` 与 `qty`。
- **主数据同步**：自动将 `trade_goods_main` 物料成本与最新采购价更新。
- **应付账款建立**：自动向 `finance_payable_main` 建立应付账款。
- **状态更新**：采购单状态自动置为 `'已入库'`，到货状态置为 `'全部到货'`。

### 场景 5：🚚 销售订单 ➔ 🚚 一键出库 ➔ 动态排他锁扣库与结转 6401/1405 凭证

#### 📌 功能定位与适用场景
客户下单发货，仓库一键出库扣库，系统自动生成销售成本记账凭证并建立客户应收账款。

#### 📝 分步操作指南
1. **新建销售单**：打开【数据模块 ➔ 进销存 ➔ 销售订单主表 (`trade_sales_main`)】，点击 **`+ 新增`**，录入客户、销售金额并保存。
2. **一键销售出库**：仓管员在销售单行点击 **`🚚 出库`** 按钮。
3. **自动库存校验**：若库存不足，系统弹出精确提示 `库存不足: 当前 20，出库 50`；若库存充足，提示 `✅ 销售单出库成功，库存已扣减并自动结转成本凭证！`。

#### 🔄 后台数据自动联动逻辑
- **库存行级锁扣减**：采用 `SELECT ... FOR UPDATE` 排他锁扣减 `trade_inventory_balance` 实际库存，写 `trade_stock_log` 日志。
- **自动生成销售成本凭证 (COGS)**：系统自动计算出库商品总成本，生成会计凭证：
  - **借：6401 主营业务成本**
  - **贷：1405 库存商品**
  - 同步更新总账 `account_subject_balance` 中 6401 与 1405 科目余额。
- **状态更新**：销售单发货状态自动置为 `'已出库'`，销售状态置为 `'已完成'`。

### 场景 6：💸 应收应付核销 ➔ 资金流水 ➔ 自动生成银行存款记账凭证 (1002/1122/2202)

#### 📌 功能定位与适用场景
客户公司账号打款回款，或向供应商付款后，财务人员在系统中进行核销拉平账目。

#### 📝 分步操作指南
1. 打开【业务操作 ➔ 应收应付核销】页面。
2. 选择切换 **【应收单】** 或 **【应付单】** 标签页。
3. 找到目标单据（如 `阳光电源` 应收单），点击行右侧 **【核销】** 按钮。
4. 在弹窗中确认或修改本次核销金额，点击 **【确认核销】**。

#### 🔄 后台数据自动联动逻辑
- **核销余额扣减**：更新 `finance_receivable_main` 的已收金额与剩余金额，状态置为 `已核销` / `部分核销`。
- **资金流水记录**：自动向资金流水表 `finance_income_main` 写入回款记录。
- **自动生成资金记账凭证**：
  - 应收核销：**借：1002 银行存款，贷：1122 应收账款**。
  - 应付核销：**借：2202 应付账款，贷：1002 银行存款**。
- **总账余额更新**：自动增减 `account_subject_balance` 银行存款与应收应付科目余额。

### 场景 7：🏗️ 生产管理 ➔ BOM展算 ➔ 领料扣库 ➔ 完工入库与成本凭证 (1405/5001)

#### 📌 功能定位与适用场景
车间生产计划排产、领料扣库、完工入库及产成品成本核算全生命周期。

#### 📝 分步操作指南
1. **创建工单**：打开【业务操作 ➔ 生产管理】，在【创建工单】表单中输入产品编码与计划数量，点击【执行】。系统自动按 BOM 结构展算生成领料单。
2. **一键领料扣库**：在右下角【待扣库领料单列表】中，找到目标领料单，点击 **`📋 一键扣库确认`**。
3. **一键完工入库/成本结算**：在右上角【现有生产工单列表】中，点击目标工单旁边的 **`📦 生产入库`**，确认入库数量；随后点击 **`💰 成本结算`**。

#### 🔄 后台数据自动联动逻辑
- **领料扣库**：扣减原材料库存，并**自动生成直接材料凭证（借:5001生产成本 贷:1403原材料）**。
- **完工入库与成本结算**：增加产成品库存，更新 `trade_goods_main` 最新单位成本，并**自动生成完工凭证（借:1405库存商品 贷:5001生产成本）**！

### 场景 8：🧮 MRP 物料需求运算 ➔ 一键拉起采购单 / 生产工单

#### 📌 功能定位与适用场景
根据顶层产品需求量，自动扣减现有库存与在途采购量，计算各阶物料的净需求，并直接转化为采购或生产指令。

#### 📝 分步操作指南
1. 打开【业务操作 ➔ MRP 运算】页面。
2. 输入产品编码与需求数量，点击 **【开始运算】**。
3. 页面下方【最近 MRP 运算建议】表格刷出展开后的物料净需求。
4. 对净需求 $>0$ 的物料：
   - 点击 **`📦 转采购单`**：自动拉起采购订单 (`trade_purchase_main`)。
   - 点击 **`🏗️ 转生产单`**：自动调用生产引擎拉起生产工单 (`prod_work_order`)。

#### 🔄 后台数据自动联动逻辑
- 公式：$\text{净需求} = \text{总需求} - \text{现有库存} - \text{在途量} + \text{安全库存}$。
- 转单后，`prod_mrp_calc.calc_status` 自动更新为 `'已转采购'` 或 `'已转生产'`，避免重复下达。

### 场景 9：🛠️ 库存直调 & 期末关账 (月结 / 年结)

#### 📌 功能定位与适用场景
无主从单据场景下的盘点调账，以及财务月末/年终损益结转与关账。

#### 📝 分步操作指南
- **盘点直调**：选择商品编码、仓库与调账数量，点击【入库】或【出库】。
- **月末结账**：
  1. 输入结账期间（如 `2026-08`），点击 **【月结处理】**。
  2. 系统自动汇总本期损益类科目（6开头），生成收入/费用结转凭证。
  3. 清零损益类科目余额，计算本期净利润转入 `4104 本年利润` 科目。
  4. 将资产/负债/权益类科目期末余额自动复制为下期期初余额。
- **年终结账**：输入年份，点击【年结处理】，将 `4104 本年利润` 余额结转入 `4103 未分配利润`。

### 场景 10：📒 会计凭证总账管理 (手工录入与借贷自动平)

#### 📌 功能定位与适用场景
财务人员手工录入非业务类凭证，或调阅系统自动生成的业务凭证。

#### 📝 分步操作指南
1. 打开【业务操作 ➔ 会计凭证】页面。
2. 填写凭证字（如`记`）、会计期间（如`2026-08`）。
3. 添加多行借贷明细（选择科目编码、摘要、借方金额/贷方金额）。
4. 校验顶部 **“借方合计 = 贷方合计”**，确认无误后点击【保存凭证】。

#### 🔄 后台数据自动联动逻辑
- 自动写入 `voucher_main` 与 `voucher_detail`。
- 自动更新 `account_subject_balance` 对应科目的本期借贷发生额与期末余额。

### 场景 11：📊 三大财务报表 (资产负债表 / 利润表 / 现金流量表)

#### 📌 功能定位与适用场景
财务主管与审计人员按期间查询企业资产、负债、利润与现金流量。

#### 📝 分步操作指南
1. 打开【业务操作 ➔ 三大财务报表】页面。
2. 选择会计期间（如 `2026-08`）。

## 3. 🏢 主数据字典 (162 张表) 在系统中的真实定位

在真实的 ERP 架构中，一线业务人员是在上述 12 个专属面板中完成工作的。这 162 张底层业务表是整个系统的 **“实体关系与数据基座 (Data Backbone)”**。

## 4. 常见报错与避坑指南

### 1. 报错 `失败: 生产入库失败: Incorrect result size: expected 1, actual 0`
- **原因**：输入的工单号在数据库中不存在。
- **解决**：先在【生产管理】中【创建工单】，随后直接在右侧【现有生产工单列表】中点击 **`📦 生产入库`** 按钮，或在下拉菜单中选择真实工单号，无需手打！

### 2. 销售出库提示 `库存不足: 当前 0, 出库 10`
- **原因**：该仓库中的商品库存余额小于出库数量。
- **解决**：请先执行【采购入库】或【生产入库】增加该商品的库存，然后再执行出库。

### 3. 新注册用户提示 `账号未审核，请联系管理员`
- **原因**：新注册账号默认处于 `pending` 状态。
- **解决**：使用 `admin` 账号登录，进入【用户管理】点击【审核通过】即可。

### 4. 导出 CSV 在 Excel 中显示乱码
- **解决**：系统导出的 CSV 已前置 UTF-8 BOM (`0xEF,0xBB,0xBF`) 字节标，直接在 Windows Excel 或 WPS 中双击打开即可正常显示纯中文。
