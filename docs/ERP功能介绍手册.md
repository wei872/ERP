## 1. 系统概述与核心优势

ERP 企业管理系统 v5.0 覆盖企业运营全流程，实现**进销存、生产制造、协同审批、财务总账与资金核销**的完整闭环。

### 🌟 核心优势

* **数据深度联动**：
  - **采购**：采购单一键入库 ➔ 自动算加权平均成本 ➔ 更新库存余额与到货状态 ➔ 挂接应付账款。
  - **销售**：销售单一键出库 ➔ 动态扣减库存 ➔ **自动生成销售成本凭证（借:6401主营业务成本 贷:1405库存商品）** ➔ 更新发货状态。
  - **核销**：应收应付一键核销 ➔ 自动生成银行存款记账凭证（借/贷 1002/1122/2202）➔ 实时同步更新总账科目余额。
  - **MRP 运算**：BOM 净需求计算后，支持一键拉起采购订单或生产工单。
  - **审批**：费用审批通过后自动生成记账凭证（借:6602管理费用 贷:1002银行存款）。
* **高性能与安全保障**：
  - **多层权限防护**：前端 JSON 权限 + 后端模块前缀强校验 + RBAC 菜单矩阵。
  - **高并发安全**：库存扣减采用 MySQL `FOR UPDATE` 行排他锁，防止超扣与数据竞争。
  - **优化数据导出**：CSV 导出自动注入 UTF-8 BOM 标志，保障 Windows Excel 打开中文无乱码。
* **极简无桩架构**：
  - 后端无桩函数、无 mock 残留，所有数据真实落库；提供 162 张业务数据表的通用 CRUD 与 LIKE 搜索。

## 3. 核心业务模块操作指南

### 3.1 📊 控制台 (Dashboard)

* **功能路径**：左侧导航 ➔ 控制台
* **核心内容**：
  - **数据 KPI 卡片**：实时统计总销售额、总采购额、总订单数、净利润、员工总数、表数量等。
  - **趋势图表**：月度销售趋势、周度销售对比、月度采购趋势。
  - **库存分布**：商品存货金额分布图（Recharts 绘制）。
  - **部门费用与热销 TOP8**：各部门人力/费用支出与 TOP8 热销商品排行。

### 3.2 📈 报表中心 (Report Center)

* **功能路径**：左侧导航 ➔ 报表中心
* **核心内容**：
  - 提供 **销售、采购、库存、财务、生产、人力** 六个维度的综合报表。
  - 支持按 **周 (Weekly)、月 (Monthly)、年 (Yearly)** 自由切换图表维度，实时从真实数据库聚合并展示。

### 3.3 🔁 工作流审批 (Workflow Engine)

* **功能路径**：左侧导航 ➔ 业务操作 ➔ 工作流审批
* **引擎规则**：
  - **采购审批**：3 级节点（部门经理审核 ➔ 总经理审批 ➔ 财务总监审批）。
  - **费用审批**：2 级节点（部门经理审核 ➔ 财务审核）。
  - **请假审批**：2 级节点（部门经理审核 ➔ HR复核）。
* **操作流程**：
  1. **发起审批**：可以在“提交新审批”标签页填写，也可以在【通用数据表 > 采购订单】中直接点击 **`🔁 提审批`** 按钮一键发起！
  2. **处理待办**：审核人在“我的待办”列表中查看申请详情（支持查看关联单号与流转日志），输入意见后点击【通过】或【驳回】。
  3. **自动联动**：
     - **采购审批通过**：自动将采购单状态置为 `'已审批'`。
     - **费用审批通过**：自动记入 `finance_expense_main` 资金支出，并**自动生成费用记账凭证（借:6602管理费用 贷:1002银行存款）**，更新总账科目余额！

### 3.4 🛒 进销存与单据智能联动 (Trade & Stock Linkage)

* **功能路径**：左侧导航 ➔ 数据模块 ➔ 贸易管理 ➔ 采购订单 / 销售订单
* **智能联动指南**：

#### 采购到入库与账务联动
1. **新建采购单**：在 `trade_purchase_main` 中新增采购单（录入供应商与总金额）。系统会自动生成初始应付账款。
2. **一键提报审批**：在采购单列表行操作栏点击 **`🔁 提审批`**，一键推送至工作流。
3. **一键采购入库**：当货物送达时，在采购单列表行点击 **`📦 入库`**：
   - 自动生成入库主明细单据 (`trade_stock_in_main/detail`)。
   - **自动计算加权平均成本**，更新库存余额与 `trade_stock_log` 日志。
   - 同步更新物料主表 (`trade_goods_main`) 的单位成本与采购价。
   - 采购单状态自动置为 `'已入库'`，到货状态置为 `'全部到货'`。

#### 销售到出库与成本结转联动
1. **新建销售单**：在 `trade_sales_main` 中新增销售单（录入客户与总金额）。系统会自动生成初始应收账款。
2. **一键销售出库**：在销售单列表行点击 **`🚚 出库`**：
   - 系统自动校验各商品库存（库存不足时弹出精确缺货提示）。
   - 自动生成出库主明细单据 (`trade_stock_out_main/detail`)，并实时扣减实际库存。
   - **自动结转销售成本（生成会计凭证）**：系统根据出库商品当前单位成本，自动生成凭证 借：`6401` 主营业务成本，贷：`1405` 库存商品，并实时更新总账科目余额。
   - 销售单状态自动同步置为 `'已出库'` 和 `'已完成'`。

### 3.5 💸 应收应付核销 (Reconciliation)

* **功能路径**：左侧导航 ➔ 业务操作 ➔ 应收应付核销
* **操作流程**：
  1. 页面分别列出当前未处理的【应收账款】与【应付账款】单据及剩余金额。
  2. 在单据行右侧输入本次核销金额（支持部分核销与全额核销），点击【核销】。
  3. **自动化联动结果**：
     - 更新对应单据的已收/已付金额、剩余金额与状态（`已核销` / `部分核销`）。
     - 自动向资金流水表（`finance_income_main` 或 `finance_expense_main`）写入核销记录。
     - **自动生成资金记账凭证**：
       - 应收核销：借 `1002 银行存款`，贷 `1122 应收账款`。
       - 应付核销：借 `2202 应付账款`，贷 `1002 银行存款`。
     - 自动增减 `account_subject_balance` 中银行存款与应收应付科目的余额！

### 3.6 🏗️ 生产管理 (Production Management)

* **功能路径**：左侧导航 ➔ 业务操作 ➔ 生产管理
* **生产全生命周期流转**：
  1. **创建工单**：输入产品编码与计划生产数量，系统自动根据 BOM 结构（`prod_bom_structure`）进行展算，生成对应的领料单 (`prod_material_requisition`)。
  2. **领料确认**：在领料确认区确认领料数量，系统**自动扣减原材料库存**，并生成直接材料记账凭证（借：`5001 生产成本`，贷：`1403 原材料`）。
  3. **报废登记**：如有生产损耗，录入报废数量与原因，更新工单报废记录。
  4. **生产入库与成本结算**：录入实际完工入库量，系统自动增加产成品库存；当全额完工时，自动汇总领料材料成本与工序成本，**生成完工入库凭证（借:1405库存商品 贷:5001生产成本）**，并将最新单位成本同步更新至物料主表。

### 3.7 🧮 MRP 物料需求运算 (MRP Calculation)

* **功能路径**：左侧导航 ➔ 业务操作 ➔ MRP 运算
* **计算公式**：  
  $$\text{物料净需求} = \text{总需求} - \text{现有库存} - \text{在途采购量} + \text{安全库存}$$
* **智能单据拉起**：
  1. 在“MRP 运算”区域输入产品编码与需求数量，点击【开始运算】。
  2. 页面下方的【最近 MRP 运算建议】列表中实时展示展开后的各物料净需求。
  3. 对净需求 $>0$ 的物料：
     - 点击 **`📦 转采购单`**：系统根据物料默认供应商与最新采购价，自动生成采购订单 (`trade_purchase_main`)，并将建议状态标记为 `已转采购`。
     - 点击 **`🏗️ 转生产单`**：系统自动调用生产引擎创建生产工单 (`prod_work_order`)，状态标记为 `已转生产`。
  4. 支持 BOM 成本递归滚算，用于查询复杂多级 BOM 产品的预测标准成本。

### 3.8 🛠️ 库存直调 & 期末结账 (Inventory & Closing)

* **功能路径**：左侧导航 ➔ 业务操作 ➔ 库存直调 & 期末结账
* **核心功能**：
  - **快速盘点出入库**：用于无主从单据场景下的库存盘点调账，直接增减库存。
  - **月末结账**：
    1. 输入结账期间（如 `2026-08`），点击【月结处理】。
    2. 系统自动汇总本期损益类科目（6开头），生成结转收入凭证与结转费用凭证。
    3. 清零损益类科目余额，计算本期净利润，将其转入 `4104 本年利润` 科目。
    4. 将资产/负债/权益类科目的期末余额自动复制为下一期间的期初余额。
  - **年终结账**：汇总全年 12 个月的净利润，将 `4104 本年利润` 余额结转入 `4103 未分配利润` 科目。

### 3.9 📒 会计凭证 (Voucher Management)

* **功能路径**：左侧导航 ➔ 业务操作 ➔ 会计凭证
* **核心功能**：
  - **手工录入凭证**：添加多行借贷明细，系统实时校验 **“借方合计 = 贷方核算”**。保存后自动插入 `voucher_main/detail` 并更新科目余额表。
  - **补生成凭证**：支持根据销售单 ID 或采购单 ID，重新触发补建会计记账凭证。
  - **凭证列表与状态查询**：查询历史记账凭证、审核状态与制单人。

### 3.10 📊 三大财务报表 (Financial Statements)

* **功能路径**：左侧导航 ➔ 业务操作 ➔ 三大财务报表
* **报表内容**：
  - **资产负债表**：根据科目编码前缀（1开头资产、2开头负债、4开头所有者权益）按期间实时计算，严格遵循 $\text{资产} = \text{负债} + \text{所有者权益}$ 会计恒等式。
  - **利润表**：实时聚合损益类科目，展示营业收入、营业成本、期间费用、毛利与净利润。
  - **现金流量表**：按现金与银行存款流水表（`finance_income_main` / `finance_expense_main`）汇总计算经营活动现金流入、流出与净流量。

## 4. 全流程数据联动矩阵

| 序号 | 业务场景 | 触发操作 | 自动化生成的关联数据与动作 |
|---|---|---|---|
| **1** | **采购入库** | 采购单列表点击 **`📦 入库`** | 1. 生成入库单据 `trade_stock_in_main/detail`<br>2. 重新计算库存加权平均成本<br>3. 增加库存余额并写入 `trade_stock_log`<br>4. 采购单状态更新为“已入库”，到货状态更新为“全部到货” |
| **2** | **销售出库** | 销售单列表点击 **`🚚 出库`** | 1. 自动校验库存（不足时精准提醒）<br>2. 生成出库单 `trade_stock_out_main/detail`<br>3. 扣减库存余额并写出库日志<br>4. **自动生成成本凭证（借:6401主营业务成本 贷:1405库存商品）**<br>5. 销售单发货状态更新为“已出库” |
| **3** | **应收/应付核销** | 核销页面点击【核销】 | 1. 扣减应收/应付待核销余额，更新单据状态<br>2. 写入资金流水 `finance_income_main`/`expense_main`<br>3. **自动生成资金凭证**（借:1002银行存款 贷:1122应收 或 借:2202应付 贷:1002银行存款）<br>4. 增减总账银行存款与应收应付科目余额 |

| **5** | **单据提报审批** | 采购单列表点击 **`🔁 提审批`** | 1. 自动推送至 3 级采购审批工作流<br>2. 流程审批通过后自动将采购单标记为“已审批” |

## 5. 常见问题与操作最佳实践

1. **新建账号登录提示“账号未审核”怎么办？**
   - 新注册账号默认处于待审核状态，请使用 `admin` 账号登录，进入【用户管理】页面，在列表中点击【审核通过】即可。
2. **销售出库提示“库存不足”如何处理？**
   - 请先在【生产管理】或【库存直调&期末】中进行商品入库或盘点调增，确保库存数量大于销售出库数量后再点击出库。
3. **导出 CSV 文件在 Excel 中打开乱码怎么办？**
   - 系统导出的 CSV 已内置 **UTF-8 BOM 字节标志**，直接在 Microsoft Excel 或 WPS 中双击打开即可正常显示中文，无需手动转换编码。
4. **月末结账能否重复运行？**
   - 月结处理具备幂等性与凭证冲销逻辑，支持对指定期间重新结账，系统会自动结转损益并更新期末期初余额。
